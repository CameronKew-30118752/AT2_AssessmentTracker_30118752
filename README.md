# AT2_AssessmentTracker_30118752
C# Assessment Tracker GUI Application for CITE-MS

## Project Overview
The Assessment Tracker is a C# application developed for CITE-MS to help users manage and keep track of their assessments. 
The application uses WPF to provide a GUI.

## Application Features
- Login: Provides an entry screen to the application.
- Main Menu: Allows users to navigate between the different application functions.
- View Assessments: Displays saved assessments in a table.
- Add Assessment: Allows users to enter and save new assessments.
- Delete Assessment: Allows users to select and remove existing assessments. 

## Assessment Information
Each assessment stores the following information:
- Unit / Cluster Name
- Assessment Name
- Assessment Type
- Due Date

## Technologies Used 
- C#
- .NET
- Windows Presentation Foundation (WPF)
- Visual Studio
- Git and GitHub

## Data Storage
Assessment records are stores in a text file named assessments.txt.
The application used a '|' character to separate assessment information within the file
